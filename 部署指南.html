黄金预测系统 · 超详细部署指南

面向零基础用户 | 跟着做就行 | 约 30 分钟完成

先读这里：这个指南分为 6 个阶段，每个阶段有若干步骤。你只需要按顺序操作，遇到不确定的地方先跳过，最后统一检查。每一步都标了预计耗时。
阶段一

注册 GitHub 账号 & 创建仓库

1
注册 GitHub 账号（约 3 分钟）

如果你已经有 GitHub 账号，跳到第 2 步。

  1. 打开 https://github.com
  2. 点右上角 Sign up
  3. 输入邮箱、设置密码、用户名（如 yourname）
  4. 完成验证码，去邮箱点确认链接
提示：用户名会成为你面板网址的一部分（如 yourname.github.io），建议用简单好记的。
2
创建新仓库（约 2 分钟）
  1. 登录后，点右上角 + 号 → New repository
  2. Repository name 填：gold-predictor
  3. Description 填：黄金每日趋势预测系统（可空）
  4. 可见性选 Public（公开——否则 GitHub Pages 免费版用不了）
  5. 勾选 Add a README file
  6. 其他都默认，点 Create repository
必须选 Public：GitHub Pages 的免费版只支持公开仓库。如果你想用私有仓库，需要 GitHub Pro 付费版。
阶段二

上传项目文件到 GitHub

3
安装 GitHub Desktop（约 5 分钟）

你不需要学命令行，用图形界面工具最简单。

  1. 打开 https://desktop.github.com
  2. 下载 GitHub Desktop（Windows/Mac 都有）
  3. 安装后打开，用你的 GitHub 账号登录
  4. 它会自动找到你刚创建的 gold-predictor 仓库
提示：GitHub Desktop 的界面是中文的（系统语言），操作和普通软件一样简单。
4
把项目文件夹克隆到本地（约 2 分钟）
  1. 在 GitHub Desktop 左上角点 File → Clone repository
  2. 选择 gold-predictor
  3. Local path 选一个好找的目录，比如 D:\gold-predictor
  4. 点 Clone

现在本地 D:\gold-predictor 只有一个 README.md 文件。

5
把系统文件复制进去（约 3 分钟）

我在你的电脑上已经创建好了所有文件，路径是：

C:\Users\15693\AppData\Roaming\TRAE SOLO CN\...\gold-predictor\

操作：

  1. 打开上面的文件夹
  2. 选中所有文件和文件夹（除了 README.md，因为 GitHub 已经有一个了）
  3. 复制（Ctrl+C）
  4. 打开本地克隆目录 D:\gold-predictor
  5. 把原来的 README.md 删掉（用我们的新 README.md 替换）
  6. 粘贴（Ctrl+V）

复制后你的目录结构应该是这样：

gold-predictor/ ├── .github/workflows/ ← 3 个 yml 文件 ├── dashboard/ │ └── dashboard.html ← 预测面板 ├── data/ │ └── .gitkeep ├── scripts/ ← 7 个 Python 脚本 ├── .gitignore ├── API_KEYS_GUIDE.md ├── README.md ← 预测规则手册 ├── log.xlsx ← 评分日志 └── requirements.txt
注意：确保 .github 文件夹也复制了（它是隐藏文件夹，可能需要先在文件管理器里开启"查看隐藏文件"）。
6
提交并推送到 GitHub（约 2 分钟）
  1. 回到 GitHub Desktop，你会看到一堆变更文件（绿色 + 号）
  2. 左下角 Summary 填：初始化黄金预测系统
  3. 点 Commit to main 按钮
  4. 然后点顶部的 Push origin 按钮
  5. 等进度条走完，所有文件就上传到 GitHub 了
成功标志：打开 https://github.com/你的用户名/gold-predictor，能看到所有文件夹和文件。
阶段三

获取 API Key（约 10 分钟）

7
获取 Tavily API Key（新闻搜索）
  1. 打开 https://tavily.com
  2. 点 Sign Up，用 Google 或邮箱注册
  3. 登录后进入 Dashboard 页面
  4. 你会看到一个 API Key（格式：tvly-xxxxxxxxx）
  5. 复制它，先存到记事本里
免费额度：1000 次/月，本系统每天用 5 次，月用约 150 次，免费够用。
8
获取 DeepSeek API Key（模型推理）
  1. 打开 https://platform.deepseek.com
  2. 注册账号（可用手机号或邮箱）
  3. 左侧菜单点 API Keys
  4. 点 创建 API Key
  5. 名字随便填（如 gold-predictor），创建
  6. 复制弹出的 Key（格式：sk-xxxxxxxxx），存到记事本
  7. 充值：左侧菜单点 充值，微信扫码充 ¥1 即可
¥1 够用多久？每次推理约 ¥0.01，每天 1 次。¥1 ≈ 100 次 ≈ 3 个月。
9
记录 LLM 配置信息

记下这 3 个值（等下要填到 GitHub Secrets 里）：

LLM_API_KEY = sk-xxxxxxxxx （你刚复制的 DeepSeek Key） LLM_BASE_URL = https://api.deepseek.com/v1 LLM_MODEL = deepseek-chat
阶段四

在 GitHub 配置 Secrets（约 5 分钟）

10
进入仓库设置页面
  1. 打开你的仓库页面：https://github.com/你的用户名/gold-predictor
  2. 点顶部标签栏的 Settings（设置）
  3. 左侧菜单找到 Secrets and variables → 点 Actions
11
添加 4 个 Secrets

点绿色按钮 New repository secret，逐个添加以下 4 个：

Name Secret
TAVILY_API_KEY tvly-xxxxxxxxx（第 7 步获取）
LLM_API_KEY sk-xxxxxxxxx（第 8 步获取）
LLM_BASE_URL https://api.deepseek.com/v1
LLM_MODEL deepseek-chat
每个 Secret 的添加方法：Name 填名称（如 TAVILY_API_KEY）→ Secret 填值 → 点 Add secret。
注意：Name 必须和上表完全一致（包括大小写），否则 GitHub Actions 找不到。
阶段五

启用 GitHub Pages（约 3 分钟）

12
配置 Pages 部署源
  1. 在仓库的 Settings 页面
  2. 左侧菜单找到 Pages（在 Code and automation 分类下）
  3. Source 选择 Deploy from a branch
  4. Branch 选 main，旁边选 /dashboard
  5. 点 Save
面板地址：保存后页面顶部会显示你的面板网址，格式为：
https://你的用户名.github.io/gold-predictor/
先记下来。
如果选不到 /dashboard：先选 main 和 /root，保存后等 1-2 分钟再回来改成 /dashboard。GitHub 有时需要先识别到分支才有下拉选项。
阶段六

手动测试流水线（约 5 分钟）

13
触发晨间流水线
  1. 在仓库页面点顶部 Actions 标签
  2. 左侧会看到 3 个 workflow：晨间流水线、午后复核、手动刷新
  3. 点 晨间流水线
  4. 右侧点绿色按钮 Run workflow → 再点 Run workflow
  5. 等 10-20 秒，刷新页面，会看到运行中的任务（黄色圈圈）
14
查看运行结果
  1. 点那个运行中的任务（标题是自动提交时间）
  2. 会看到 4 个步骤：1/4 结算昨日预测 → 2/4 采集今日数据 → 3/4 模型推理 → 4/4 部署面板
  3. 等绿色 ✓ 全部亮起（约 2-3 分钟），表示成功
  4. 如果有红色 ✗，点进去看日志，通常是 API Key 填错或额度不足
成功标志：仓库里 log.xlsx 和 dashboard/dashboard.html 有新的提交记录（提交者 github-actions[bot]）。
常见报错排查：
• TAVILY_API_KEY not set → Tavily Key 没填或拼错
• LLM_API_KEY not set → DeepSeek Key 没填
• 401 Unauthorized → Key 无效或已过期
• Insufficient balance → DeepSeek 余额不足，充 ¥1
• 金价/VIX 获取失败 → 网络波动，重跑一次
15
访问你的预测面板

打开浏览器，访问：

https://你的用户名.github.io/gold-predictor/

你会看到黄金预测面板，包含当日预测、实时金价、60日走势图、历史记录、要闻等全部板块。

手机也能看：这个面板是响应式设计，手机浏览器打开同样美观。
首次部署可能需要等 1-2 分钟：GitHub Pages 第一次构建需要时间。如果打开是 404，等 2 分钟再刷新。

日常使用说明

自动运行

  • 每天 06:30（北京时间）：自动跑晨间流水线——采集数据→AI推理→生成预测→更新面板
  • 每天 15:35（北京时间）：自动跑午后复核——只更新实时金价，不推翻早上的预测
  • 次日 06:30：自动结算昨天的预测——回填实际价→打分→更新胜率
  • 你什么都不用做，每天打开面板看结果就行

手动刷新（盘中想看最新行情）

  1. 打开面板网页
  2. 点右上角 ⟳ 立即刷新 按钮
  3. 页面顶部显示进度条：排队中 → 采集中 → 推理中 → 更新面板
  4. 约 1-3 分钟后面板自动刷新，显示最新金价
  5. 20 分钟内不可重复点击（限流防滥用）

查看历史记录

  • 面板"历史预测记录"表格会自动更新
  • log.xlsx 文件也同步更新（在 GitHub 仓库里直接查看）
  • 攒够 20 个已结算样本后，系统自动出置信度校准报告

完成检查清单

  • GitHub 账号已注册
  • 仓库 gold-predictor 已创建（Public 可见性）
  • 所有文件已上传到仓库
  • Tavily API Key 已获取并存入 Secrets
  • DeepSeek API Key 已获取并存入 Secrets（LLM_API_KEY、LLM_BASE_URL、LLM_MODEL）
  • DeepSeek 已充值 ¥1
  • GitHub Pages 已启用（Source: main / /dashboard）
  • 晨间流水线手动触发成功（4 步全绿 ✓）
  • 面板网页能正常打开
如果遇到任何问题：把 GitHub Actions 的报错日志截图发给我，我帮你排查。最常见的 3 个问题：API Key 拼写错误、DeepSeek 没充值、GitHub Pages 还没生效（等 2 分钟）。
